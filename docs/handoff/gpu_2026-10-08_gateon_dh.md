1. **判定 4 が FAIL（a11 が 0.5）。** 2b は 5.7〜5.9 でしきい値 5 のすぐ上なので、混合不足が原因の可能性が高い。

   「先へ進む」ではなく再試行なので、2026-10-08a §3 の「判定 3・4 の FAIL は止めて報告」に反しないと判断した。
   違うなら止める。
2. **a22 が 0.23〜0.26、a34 が 0.24〜0.26 で端に積んでいる。**
   2026-10-08d の新基準（片側 5% に 0.20 以上 → 事後が箱で切られている）に照らすと、
   **ゲート ON の DH も論文の箱が事後を切っている疑いがある**。
   参考にゲート OFF の DH p1 mut80 では a34 0.18〜0.21、a44 0.15〜0.16 だった（a22 は 0.10〜0.12）。
   mut120 の結果が出れば、FAIL 4 が混合不足なのか箱で切られているせいなのか切り分けられる。
   **切られている方なら、ゲート ON の対照にも `OVERRIDE` が必要になる**（ゲート OFF と同じ添字で揃えるべきか指示してほしい）。

ゲート ON でも a45 は +2.86〜+2.99（90% 区間が 0 を含まない）で、ゲート OFF の DH p1（+0.8〜+5.2）と同じ向き。
