## 1. 本題: DS の ln B が負で大きい。箱の幅のせいだが、額面どおり読まれると危ない

a45 = 0 の run が揃ってきたので現時点の ln B を出した（`tools/bayes_factor_a45.py`）。
**3 seed 揃っていない群は解釈しない**という前提のうえで、傾向だけ先に共有する。

| 条件 | a45 の箱（幅） | seed | ln B = lnZ(自由) − lnZ(a45=0) | 判定 |
|---|---|---|---|---|
| CS | [−1, 1]（2） | 42 | **+0.198** | 差とは言えない |
| CS | [−1, 1]（2） | 123 | **+0.109** | 差とは言えない |
| CH | [−1, 2]（3） | 42 | **−0.062** | 差とは言えない |
| DH | [−0.5, 6]（6.5） | 7 | **+1.407** | 弱く a45 自由を支持 |
| **DS** | **[−15, 20]（35）** | **7** | **−3.038** | **強く a45 = 0 を支持** |
| **DS** | **[−15, 20]（35）** | **123** | **−1.903** | **弱く a45 = 0 を支持** |

### 何が危ないか

**DS は dysbiotic なのに「a45 = 0 を支持」と出る。** DH は +1.41 で逆向き。
このまま表に載せると「dysbiotic でも DS では Pg の相互作用が要らない」と読まれて、
論文の筋（a45 は dysbiotic で正）と衝突する。

原因はほぼ確実に事前分布の幅。DS だけ a45 の箱が [−15, 20]（幅 35）で、
自由モデルにかかる Occam の罰は $\ln 35 = 3.56$。CS の $\ln 2 = 0.69$ より **2.86 nat 重い**。
符号が反転する大きさとして order は合っている。原稿の「保守的」の一文はこれを指しているはず。

### ただし「箱を狭めれば +0.9 になる」とは書けない

幅の付け替えで $\ln B$ を $\ln(35/2) = 2.86$ だけ動かす補正は、
**a45 の事後が両方の箱に収まっているときだけ**成り立つ。実際は収まっていない:

- DS の a45 事後: MAP **+2.72**、90% 区間 **[+0.04, +4.27]**
- DH の a45 事後: MAP **+1.95**、90% 区間 **[+0.88, +5.35]**

CS の箱 [−1, 1] に入れ直すと事後が切られるので、単純な幅の補正では換算できない。
**「DS の −3.0 は箱の幅で説明がつく」とは言えるが、「本当は +0.9 だ」とは言えない。**

### 提案（判断をあおぎたい点）

条件間で ln B を横並びにしたいなら、**4 条件すべての a45 事後を含む共通の箱**で取り直すのが筋だと思う。
上の区間から **[−1, 6]**（幅 7）なら CS・CH・DS・DH の事後をすべて含み、どの条件も事後を切らない。
その箱なら ln B は条件間で直接比較でき、「dysbiotic（DS・DH）では a45 自由が支持され、
commensal（CS・CH）では差が出ない」という筋がそのまま言える（はず）。

- 案 A: **共通の箱 [−1, 6] で a45 自由 / a45 = 0 を 4 条件 × 3 seed**。pilot なので 24 本。
  ただし DS は a33・a34 の箱を [−15, 20] にしたままにする必要がある（そこは別問題なので触らない）
- 案 B: **現状のまま。条件ごとに箱の幅を併記し、ln B は条件内でだけ読む**（2026-10-08i の方針）。
  この場合 **DS の −3.0 をどう書くかを本文で決めてほしい**。「箱が広いぶん a45 = 0 寄りに出る」
  だけだと、査読者は「ではなぜ DS だけ箱を広げたのか」と聞いてくると思う
- 案 C: DS の ln B は**載せない**（a33 の二峰で DS 自体が「弱く同定」なので、
  Bayes 因子を出す段ではないという整理）

24 本は枠を食うので、案 A をやるなら本線（DS p1 → p2 → ult）の後になる。10-16 投稿に間に合うかは
そちらの判断。**こちらの推しは案 B + DS は「箱の幅のため解釈しない」と一文入れる**（追加計算ゼロ）。
