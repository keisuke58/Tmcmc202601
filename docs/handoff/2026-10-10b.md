## 2. DS: 18000 粒子で p2 を回し直す

診断（`gpu_2026-10-10_mode_split_DS.md`）で、a12 は同定されていない（平ら）・a34 は二峰で山の中はそろう・a55 は 0.51 で境界。新しい規則なら残るのは a55 だけなので、粒子を 1.5 倍にして通す。

```
STAGE=p2 TAG=DS SEED=$S N_PART=18000 N_MUT=150 RUNTAG=wide80_p18k_wide2
OVERRIDE='5:-15:20;6:-15:20;19:-15:20;14:-5:4;12:-5:3;16:-5:2.5'
PREV=_runs/paper_gateoff/DS_p1_wide80_p3k_seed$S
```

- gate は `MODES='a34:-1.5'` で仕掛ける。ult は `N_MUT=150 RUNTAG=wide80_p18k_wide2_sd4`。
- **先に、いまの 12000 粒子の run を新しい規則で読み直して報告してほしい**（`--modes 'a34:-1.5'`）。それで通れば 18000 は不要で、12000 から ult に進める。
