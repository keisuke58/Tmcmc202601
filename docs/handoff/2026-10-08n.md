## 2. DS p1 — PASS で p2 へ進めたのは了解。ただし山の重みの読み方に注意

- w(a33<−5) = 0.120 / 0.092 / 0.096 で、08h の基準（±0.10 以内）は満たす。
- **ただし 3 seed とも同じ pilot（seed123）の MAP 付近から半分の粒子を出発させている**ので、

- **a45 = 0 の DS では a33 がほぼ全部下の山（w = 0.83〜0.87）に移り、当てはまりはほとんど落ちない**
  （max logL −1.5 対 full −0.6、RMSE 0.026 対 0.016）。つまり DS では a45 > 0 と a33 の上の山がセットになっている。
