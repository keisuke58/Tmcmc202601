### (b) a11 が下限 0 に張り付いている（これが主因だと思う）

| | a11 の箱 | a11 の 5 / 50 / 95% | 下端 5% の割合 |
|---|---|---|---|
| DH p1 s7 | [0, 5] | +0.18 / **+2.14** / +4.59 | 0.07 |
| **DH p2 s7** | [0, 5] | +0.01 / **+0.09** / +0.35 | **0.87** |
| **DH p2 s42** | [0, 5] | — | **0.88** |

p1 では中央値 +2.14 で箱の中に収まっていたのが、p2 では**中央値 +0.09・粒子の 87〜88% が下限 0 の近傍**。
a14 も 0.18 / 0.21（p1 は 0.07）で基準に触れる。**混合不足ではない**（移動 7.6〜7.7 回/次元で 2b は PASS、受理率 0.12）。

**重要: この a11 の箱 [0, 5] は論文の箱で、OVERRIDE ではない。**
DH p2 の OVERRIDE は `12:-15:20;5:-15:20;6:-15:20;18:-15:20;13:-15:20`（a23・a33・a34・a35・a24）で a11 を含まない。
CS では a11 ∈ [0, 2]。つまり **a11 ≥ 0 は論文の事前分布が意図した符号制約**で、
multichannel 尤度は a11 < 0 を要求しているのに制約で止められている、という状態。

### 聞きたいこと

1. **a11 ≥ 0 は物理的に意図した制約か**（So の自己相互作用なので非負が自然に見えるが、確証がない）
   - **意図した制約なら**: 張り付きは「データは a11 ≤ 0 を示すが、モデルは a11 = 0 を選んだ」と解釈し、
     原稿に「a11 は下限に達した」と書いて ult に進める（＝ `qrls` する）
   - **08k の「端に積んだら箱を広げる」を適用するなら**: a11 を負に広げて p2 を回し直す。
     ただし a11 < 0 は So の自己促進を意味するので、モデルの前提が変わる話になる
2. **判定 4 FAIL（a55 0.6 sd）をどう扱うか。** 08k は「3・4 の FAIL は止めて報告」なので止めた。
   a55 は Pg の自己相互作用で、DH では活発な成分。粒子を増やす（p2 を 3000 粒子にする）案もある
3. seed123（3192、経過 7:25、seed7 は 7.3h で完走したので間近）を待ってから判断してよいか

**DH ult は qhold 済みなので、判断までに勝手に走り出すことはない。**
