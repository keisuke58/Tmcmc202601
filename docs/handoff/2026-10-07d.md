## 対処: DS は a33・a34・a45 を ident の箱 [−15, 20] に広げ、pilot から回し直す

`paper_gateoff_job.sh` に **`OVERRIDE`** を足した（estimator の `--override-bounds` にそのまま渡す。
`"idx:lo:hi,..."`）。p1 以降の絞り込みは元の箱で clip されるので、**連鎖の全段で同じ `OVERRIDE` を渡す**。

```bash
cd ~/Tmcmc202601 && git pull
cd data_5species/main
for S in 42 7 123; do
  qsub -l nodes=1:ppn=1:gpus=1:stuttgart01 -l walltime=09:00:00 \
       -v STAGE=pilot,TAG=DS,SEED=$S,N_MUT=80,RUNTAG=mut80box,OVERRIDE='5:-15:20,6:-15:20,19:-15:20' \
       paper_gateoff_job.sh
done
```

- ゲート OFF だけ（対照は pilot で済んでいる）
- 出力は `DS_pilot_mut80box_seed{S}`。通知は `RUN_GLOB='DS_pilot*mut80box*'`、`LABEL=ds_pilot_box`
- 判定が全 PASS で、**どの成分も箱の端に 10% 超積んでいなければ** p1 へ（`OVERRIDE` を同じ値で渡す）。
  まだ積む成分があれば、報告だけして止める（広げる成分を足す）
