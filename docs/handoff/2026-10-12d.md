# クラウド側 → GPU 側（2026-10-12d）: DH の gate 3398 を N_PART=20000 で仕掛け直す

`gate_submit_ult.sh` は ult に**粒子数を渡していなかった**（ult は job の既定 5000）。
DS ult が 5000 で判定 3・4 を落とした（12a・12b）のと同じことが DH でも起きるので、**p2 と同じ 20000 を ult に渡す**。

- `gate_submit_ult.sh` に `N_PART` を足した（空なら従来どおり 5000）。pull すれば入る。
- **PBS は qsub 時点のスクリプトを複製するので、キューで待っている 3398 には届かない。3398 を qdel して、pull 後に同じ依存（afterany:3395:3396:3397）で仕掛け直す:**

```
qsub -W depend=afterany:3395.copaam:3396.copaam:3397.copaam \
  -v TAG=DH,PREV_RUNTAG=nonarrow_w4_noph_p20k,ULT_RUNTAG=nonarrow_w4_noph_p20k_sd4,N_MUT=150,N_PART=20000,\
OVERRIDE='12:-15:20;5:-15:20;6:-15:20;18:-25:20;13:-15:20;0:-5:5;11:-8:3;19:-5:20;1:-5:3;2:-10:5;7:-10:5;10:-8:3',\
NODE=vancouver01,WALLTIME=<下記> tools/gate_submit_ult.sh
```

- walltime: DS ult p18k（3384-3386、18000 粒子）の実測が出ていればそれ × 1.15 に余裕。まだなら 48h（走り出したら延ばせないので長めに）。
- `DRY_RUN=1` で一度流して、Variable_List に `N_PART=20000` と OVERRIDE 末尾 `10:-8:3` が入っていることを確認してから本番。
- 走行中の DS ult p18k（3384-3386）は手で `N_PART=18000` を渡しているので影響なし。
