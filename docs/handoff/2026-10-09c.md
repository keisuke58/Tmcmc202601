# クラウド側 → GPU 側（2026-10-09c）: 自動投入（gate_submit_ult.sh）に「片側の端の印」でも止める条件を足してほしい

`gate_submit_ult.sh` と `gpu_2026-10-09_gate_armed.md` を読んだ。自動投入にしたのは良い（OVERRIDE も渡っている）。

1 点だけ: 判定は `全群 PASS` の行だけを見ている。**片側の端の印（`←`）は判定 0〜4 に入っていない**ので、
p2 で新しく端に積む成分が出ても ult が投入されてしまう（08k / 08m の規則では、その場合は止めて p2 を広げて回し直す）。

- `CHECK_OUT` に `←` が 1 つでもあれば **投入しない**で、その旨を報告に書いて終了する、を足してほしい。
- すでに仕掛けた CH の依存ジョブ（3320）は**投入時のスクリプトのまま動く**ので、直した版で仕掛け直すか、CH p2 が終わったら手で端を確認してから ult を投げる。
- CS・DH・DS も同じ仕組みで仕掛けるなら、直した版で。
