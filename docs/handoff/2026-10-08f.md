## 1. ult の箱: 平均 ± 2σ → **± 4σ**（job の既定を変えた）

- 理由: ± 2σ だと、よく決まる成分ごとに事後の約 5% を切り落とし、10 成分あれば事後全体の 3〜4 割が箱の外に落ちる。
  同じデータの事後で箱を作るので、統計の査読者が指摘しやすい。± 4σ なら成分ごとに 0.01% 未満で、受理率もほぼ変わらない（シミュレーションで確認）。
- **ult は RUNTAG の末尾に `sd4` を付ける**（± 2σ の run と glob で区別するため）:

  | 条件 | ult の RUNTAG | OVERRIDE（p2 と同じ） |
  |---|---|---|
  | DH | `nonarrow_sd4` | `'12:-15:20;5:-15:20;6:-15:20;18:-15:20;13:-15:20'` |
  | DS | `wide80_sd4` | DS の pilot〜p2 と同じ |
  | CS / CH | `sd4` | なし |

  粒子数・mutation・walltime は 2026-10-08a のとおり（5000 粒子・mut80・22h）。`ULT_NSIGMA` は渡さなくてよい（既定 4）。

## 2. 追加する run（すべて pilot 段 = 事前分布から出発するので ln Z が使える）

### (a) λ の感度 — DH、3 seed

```
STAGE=pilot TAG=DH N_MUT=80 LAMBDA_PG=1 LAMBDA_LATE=1 RUNTAG=lam1
```
比べる相手は `DH_pilot_mut80_*`（同じ箱・重みだけ違う）。見るもの: a45 の符号と 90% 区間、Pg D21/D15、RMSE。

### (b) a45 = 0 のモデル比較 — 4 条件 × 3 seed

a45（添字 19）を 0 に固定した縮小モデル。full モデルの pilot と ln Z を比べる（Bayes 因子）。

| 条件 | OVERRIDE | 比べる full の pilot |
|---|---|---|
| DH | `'19:0:0'` | `DH_pilot_mut80_*` |
| DS | `'5:-15:20;6:-15:20;19:0:0'` | `DS_pilot_wide80_*` |
| CS | `'19:0:0'` | `CS_pilot_mut80_*` |
| CH | `'19:0:0'` | `CH_pilot_mut80_*` |

```
STAGE=pilot TAG=<条件> N_MUT=80 RUNTAG=a45zero OVERRIDE=<上の表>
```
**ログに `Override bound [19] -> [0, 0]` が出ていることを確認する**（`Cannot override locked index 19` が出たら止めて報告）。
報告では、条件ごとに ln Z（3 seed の平均と幅）を full と a45 = 0 の両方で並べる。

### (c) ult ± 2σ（残すだけ。付録・査読への回答用）— 4 条件 × 3 seed

```
STAGE=ult ULT_NSIGMA=2 RUNTAG=<上の表の sd4 を sd2 に替えたもの> （PREV・OVERRIDE は sd4 と同じ）
```
**投稿（10-16）に間に合わなくてよい。** 出力は消さずに残す。
