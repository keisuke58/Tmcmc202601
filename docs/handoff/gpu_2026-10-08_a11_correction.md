# GPU 側 → クラウド側（2026-10-08）: **訂正 — a11 ≥ 0 は符号制約ではない。箱を広げてよい（判断が単純になる）**

`gpu_2026-10-08_dh_p2_stop.md` §1 で「**a11 ≥ 0 は論文の事前分布が意図した符号制約**」と書いたが、**これは誤り**だった。
箱の定義ファイルを確認した結果、判断は当初より単純になる。**まだ何も投げ直していない。**

## 根拠: 箱は条件ごとの経験的な値で、a11 の下限 0 は普遍的でない

箱は `data_5species/model_config/prior_bounds_paper_20d.json` が持っている。ファイル自身の説明:

> "Prior bounds for 5-species model. **Widened to contain all TMCMC MAP values + posterior mass (2026-03-17).**"

つまり **2026-03-17 時点の（ゲート ON の）事後を包むように経験的に広げた箱**で、理論から来た制約ではない。

a11（index 0）の下限は条件ごとに違う:

| param | CS | **CH** | **DS** | DH |
|---|---|---|---|---|
| **a11** | [0, 2] | **[−1, 1.5]** | **[−1, 2]** | [0, 5] |
| a14 | (既定 [−1,1]) | [−1, 1] | [−1, 1] | [−1.5, 3] |

**CH と DS は a11 < 0 を既に許している。** したがって a11 ≥ 0 は符号制約ではなく、CS と DH でたまたま下限が 0 なだけ。
BMB 原稿にも符号制約・非負制約の記述は無い（`sign constraint` / `non-negativ` / `positivity` を grep して 0 件）。

## 何が起きているかの正しい理解

DH の a11 の箱 [0, 5] は **3 月のゲート ON の事後に合わせた箱**。
ゲート OFF ＋ multichannel の p2 はこれと違う領域（a11 < 0）を要求しているので、古い箱の下限で止まっている。

- DH p1（組成のみ）: a11 中央値 **+2.14**、下端 5% の割合 0.07 → 箱の中に収まっていた
- DH p2（multichannel）: a11 中央値 **+0.09**、下端 5% の割合 **0.87 / 0.88**（2 seed で再現）

**08k の「端に積んだら箱を広げる」をそのまま適用すればよい案件で、モデルの前提は変わらない**
（CH・DS が既に a11 < 0 を許しているので）。前回「a11 < 0 は So の自己促進を意味するのでモデルの前提が変わる」と
書いたのも、この点で言い過ぎだった。

## 提案

DH p2 を `OVERRIDE` で a11（と a14）を広げて回し直す。他条件が許している範囲に合わせるなら:

```
STAGE=p2 TAG=DH SEED=$S N_MUT=80 RUNTAG=nonarrow_a11
OVERRIDE='12:-15:20;5:-15:20;6:-15:20;18:-15:20;13:-15:20;0:-5:5;11:-3:3'
PREV=_runs/paper_gateoff/DH_p1_mut80_seed$S
```

- `0:-5:5` = a11 を [−5, 5]（下限だけ対称に広げる。上限 5 は現状どおり）
- `11:-3:3` = a14 を [−3, 3]（p2 で下端 0.21 に積んでいる。現状 [−1.5, 3]）
- それ以外は現行の DH p2 と同じ

**判定 4 FAIL（a55 0.6 sd・a45 0.5 sd）が a11 の張り付きの副作用なのかは、これを回せば切り分けられる。**
a11 が箱の中に収まっても判定 4 が FAIL のままなら、そこで粒子数を増やす（3000）話になる。

### 確認したいこと

1. この OVERRIDE で回し直してよいか（a11 の下限をどこまで広げるか。[−5, 5] は提案値で、[−1, 5] に留める案もある）
2. 回し直すと DH は p2 からやり直しになるので **10-12 夜の ult に間に合うか**（DH p2 は 1 本 7.3h）。
   間に合わないなら、a11 の張り付きを承知のうえで現行 p2 のまま ult に進める選択もある（その場合は原稿に明記が必要）
3. **DH ult 3222-3224 は `qhold` のまま**にしている。回し直すなら不要になるので qdel してよいか
