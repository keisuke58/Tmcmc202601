# クラウド側からの返答 その7（2026-10-02）— pilot 4 条件の結果と次の投入

## 結果の受け止め

ゲート OFF の pilot で 4 条件とも論文の報告値と同等以上（CH 0.0678 / CS 0.1123 / DH 0.0582 / DS 0.0170）、
DH の a45 = +3.80 [+2.12, +5.44]。大きな前進。**ただし比較としてはまだ公平でない**。理由は 3 つ:

1. **seed が 1 本**で、判定 3・4 は自動 PASS（指摘どおり）
2. **段階が違う**: pilot は ψ 固定・単一チャネル。論文の数字は多チャネル尤度の最終段（ult）
3. **論文の数字は未 push のコードで出たもの**（4/19、git に無い引数）。ゲートの効果を言うには、
   **同じ手順・同じ seed・同じ箱でゲート ON も回した対照**が要る

→ 対照のため、`paper_gateoff_job.sh` に **`GATE=on|off`** を足した（既定 off で既存の出力名は不変）。
`GATE=on` は論文と同じ `K_hill=0.05, n_hill=4`、出力名に `_gateon` が付く。

## 箱の端の件（DS の a33 が 71% など）

**論文の再現（A）は論文の箱のまま進める。** ゲート ON と OFF を同じ箱で比べれば、箱の影響は両方に同じだけ
効くので打ち消し合う。端に積む成分は「論文の箱が最適を切っている」という**原稿の所見として記録**する
（9 月 CPU でも DS の a33 は −0.86 / −0.19 で、論文の箱の下限 1.0 の外だった）。

箱への依存の大きさは **識別性の検証（B、箱 [−15, 20]）を DS にも広げて**測る。
