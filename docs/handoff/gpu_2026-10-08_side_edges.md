```
          箱の端 5% に 10% 超（一様なら 0.10）: {'a13': 0.14, ...}
```

## 3. 実装して出てきた問題: **CH p2 の a13 は「前段から +0.14〜0.17」で基準に当たる**

`gpu_2026-10-08_p2_verdicts.md` §1 で「a13 は 0.20 未満・前段から減った → 触らない」と書いたが、
**あのとき私が「前段」と呼んだのは同じ段の前の箱（`CH_p2_mut150` の 0.19）だった。**
規則どおり前段（p1）と比べると増加分は +0.14〜0.17 で、増加の基準に当たる。報告が不正確だった。

ただし **p1 と p2 では箱も尤度も違う**ので、この比較が意味を持つのか自信がない。中身は:

| run | a13 の箱 | 5 / 50 / 95% | 下側 / 上側 |
|---|---|---|---|
| CH p1 `mut150` | [−0.5, 3] | +0.90 / **+1.93** / +2.84 | 0.00 / 0.06 |
| CH p2 `mut150` | [−1, 3] | −0.94 / **−0.51** / −0.14 | 0.17 / 0.00 |
| CH p2 `mut150_wide` | [−1, 3] | −0.93 / **−0.48** / −0.13 | 0.14 / 0.00 |

- **p1 → p2 で a13 の符号が変わっている**（+1.9 → −0.5）。多チャネル尤度（p2）にすると a13 は負に行く。
  片側の割合が 0.00 → 0.14 に増えたのは「箱が変わったから」ではなく **尤度が変わって事後が反対の端に移った**から。
- p2 の事後は下限 −1 に寄っていて（95% 点が −0.93）、**論文の箱の下限が a13 を切っている可能性が高い**。
  絶対値は 0.14〜0.17 で 0.20 には届かない。
- 08d の「前段から +0.1 以上」は**同じ尤度の段どうし**を想定した基準だと思うので、p1 と p2 の比較に当てるのは筋が違う気がする。
  一方、a12・a14・a15 を広げた根拠（`mut150` → `mut150_wide`）も同じ 0.20 基準なので、a13 だけ見逃すと一貫しない。

### 聞きたいこと

1. **CH ult（3288-3290）をそのまま走らせてよいか。** 走らせるなら a13 は [−1, 3] のまま（論文の箱）。
2. 広げるなら **いま qdel して `17:-5:3`（a13 の下限だけ −5）を足した p2 からやり直す**ことになる。
   CS と同じ扱いにするならこれ。22h の ult を 3 本捨てても、まだ 5 分しか走っていないので損は小さい。
3. **印の基準を「前段が同じ STAGE のときだけ増加を見る」に変えるか。** 変えるなら実装する。
   いまは段をまたいで比べるので、p1 → p2 で尤度が変わる所で必ず印が付く（CS も `0.00/0.14` → `0.00/0.23` で両方の基準に当たっている）。
