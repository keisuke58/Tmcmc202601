## 追記: 全菌の RMSE が holdout と full でほぼ同じ理由（確認済み）
- **一致はしていない**: Day 10 は 0.0601 / 0.0596、Day 15 は 0.0718 / 0.0717。小数 3 桁で丸めると同じになるだけ。
- **バグではない**: 全菌の組成は尤度に入っている（`estimate_paper_jax.py` の Ch2、`lambda_ch2=1.0`）。`--holdout-day` は外した日を多チャネルのデータごと消す（`days_filter=t_days`）ので、holdout の run は外した日の全菌も見ていない。評価する側（`holdout_eval.py`）も holdout と full で同じ関数を通している。
- **理由**: 予測の中央値が両方の群でほとんど同じ（種ごとの差 ≤ 0.008）で、誤差の大部分は 1 日外しても動かないずれから来ている。
  - Fn・Pg: 観測 0 に対して予測 0.048 前後（両群・両日とも）
  - Day 10 は Vd（予測 0.17 / 観測 0.28）が二乗誤差の 7 割、Day 15 は An（予測 0.16 / 観測 0.28）が最大
  - つまり全菌の組成は 1 日のデータでは動かず、残りの日とモデルの形で決まっている。「外しても悪くならない」とは言えるが、「予測できている」とは言えない（90% 区間に 0〜2/5）。

## 追記 2: 全菌の Pg が観測 0 に対して 0.04〜0.05 になる理由（確認済み）
**モデルの φ の式の境界項（Kp1 の壁）が、φ を 0 に近づけない下限を作っている。** 推定の失敗ではなく、モデルの形によるもの。

- 初期値の Pg は Day 1 の観測 0 を `np.clip(…, 0.001, 0.99)` で切った **0.001**（run_record の phi_init）。
- `hamilton_ode_jax_paper.residual` の φ の式に `t1 = Kp1·(2−4φ)/((φ−1)³φ³)`（Kp1 = 1e-4 固定、推定しない）がある。大きさは φ=0.001 で −2×10⁵、0.01 で −202、0.035 で −4.8、0.1 で −0.22。φ が小さいほど壁が強く、相互作用の項（c·ψ·(Aφψ)、O(1〜10)）と釣り合うところまで φ が押し上げられる。
- MAP の軌道（CH p2 seed42、ho10 も同じ）: Pg の φ は**最初の 1 日で 0.001 → 0.034**、以後 0.037〜0.039 で止まる（全菌の割合 0.04）。同時に ψ は 0.999 → 0.04 に落ちるので、生きた菌の Pg（φψ）は ~0.0016 と小さく、生きた菌の観測 0 には合っている。
- **Kp1 を変えると下限が動く**（同じ θ、Day 21 の Pg の φ）: 1e-4 → 0.037、1e-5 → 0.008、1e-6 → 0.004。（Kp1 を変えると Fn が暴れるのは θ が 1e-4 で推定されているため。下限の確認だけに使った）
- θ は Pg を抑える側の端に張り付いている（So–Pg −5.0、An–Pg −4.86、Vd–Pg −4.81、箱の下端 −5）。Pg の行を 0 にすると Day 10 の φ は 0.055。相互作用を箱の端まで使っても 0.039 までしか下がらない。
- Fn（全菌の観測も Day 10・15 で 0）が 0.04 前後で止まるのも同じ壁による。
- → 本文/補足に書くなら: 「全菌の組成で観測 0 の種（Fn・Pg）は、モデルの体積分率が境界項により ~0.04 を下回れないため、0.05 前後のずれが残る（生きた菌の組成では ψ が小さくなるので合う）」。
