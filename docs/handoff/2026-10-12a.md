# クラウド側 → GPU 側（2026-10-12a）: DS ult は 18000 粒子で回し直し＋診断、DH 仮 ult が切れたら 18h で投げ直し

`DS_ult_wide80_p18k_wide2_sd4` の自動通知（2026-10-12）を読んだ。判定 0・1・2・2b は PASS、**判定 3 FAIL**（max logL 幅 1.24：seed7 −6.06、他 2 本 −7.26・−7.30）、**判定 4 FAIL**（a34 0.65・a23 0.63・a13 0.55）。
p2 は 12000 粒子で落ち、18000 粒子で通った。**ult だけ既定の 5000 粒子に戻っているのが一番疑わしい。** 09f と同じく、診断と回し直しを同時に進める。

## 1. DS 診断（CPU・すぐ。回し直しを待たない）

```
PY=~/miniforge3/envs/klempt_fem2/bin/python3
R=data_5species/main/_runs/paper_gateoff
$PY tools/polish_max_logL.py $R --glob 'DS_ult_wide80_p18k_wide2_sd4_seed*' \
    --json docs/handoff/gpu_2026-10-12_DS_ult_polish.json
$PY tools/mode_split_check.py --param a45 --param a34 --param a23 --param a13 \
    $R/DS_ult_wide80_p18k_wide2_sd4_seed{42,123,7}
```

- **磨いたあとの max logL の幅が 1 以下 → 探索不足**（粒子を増やせば直る見込み）。**1 を超える → 本当に別の山**。
- 3 seed の MAP（15 成分）を並べた表と、a45 の 5/50/95%（seed7 だけ中央値 +1.4、他は +3.5 前後）も。
- 結果は `docs/handoff/gpu_2026-10-12_DS_ult_diag.md` に書いて push。

## 2. DS ult を 18000 粒子で回し直す（4090 のみ）

```
STAGE=ult TAG=DS SEED=$S N_PART=18000 N_MUT=150 RUNTAG=wide80_p18k_wide2_sd4_p18k
OVERRIDE='5:-15:20;6:-15:20;19:-15:20;14:-5:4;12:-5:3;16:-5:2.5'
PREV=_runs/paper_gateoff/DS_p2_wide80_p18k_wide2_seed$S
```

- seed 42・123・7。**walltime は 5000 粒子の ult（3371-3373）の実測 × 約 3.6 に余裕を足した値**（投入前に決める。走り出したら延ばせない）。
- 4090 は DH p20k（3375-3377）が使っているので、空いた枚から順に。DH p20k より後回しでよい。
- notify（`DS_ult_wide80_p18k_wide2_sd4_p18k_seed*`）を依存で仕掛ける。
- **18000 でも判定 3・4 が FAIL で、§1 で「磨いても幅 > 1」なら止めて報告**（別の山として原稿で扱う）。
- 旧 `DS_ult_wide80_p18k_wide2_sd4`（5000）は消さずに残す。
