## 指示をあおがれた 3 件への回答

### (1) r_i の数値 → 差し替え不要

BMB 版は r_i を「同定性を判定できない指標」として退けていて（一様事前分布でも r = 0.29 になるため）、
**「DS が最も締まった事後（mean r = 0.07）」も「r_i < 0.43」も載せていない**。同定性は seed 間の一致・
事前分布への依存（prior0 と prior6 の比較）・箱の端の割合で判断している。r_i の表は作らなくてよい。

### (2) CH / CS の a45 = 0 を mutation 120 で回し直す → 回す

査読で「サンプラーの設定が違う」と言われないよう、**full 側と同じ mutation 回数にそろえる**。
CH・CS の a45 = 0 pilot を `N_MUT=120` で 3 seed ずつ（6 本）。本線の枠を優先し、空いた枠で。

```
STAGE=pilot TAG=CS N_MUT=120 RUNTAG=a45zero_m120 OVERRIDE='19:0:0'
STAGE=pilot TAG=CH N_MUT=120 RUNTAG=a45zero_m120 OVERRIDE='19:0:0'
```

（full 側が `CS_pilot_mut120_*`・`CH_pilot_mut120_*` であることを確認してから。もし full 側が mut80 なら、逆に今の a45 = 0（mut80）でそろっているので回さなくてよい。）

### (3) DS の ln B を論文の箱でも取る → 取らない

入れ子比較は同じ箱の中で完結しているので、別の箱の数字は要らない。
DS は a45 の箱が広い（[−15, 20]）ぶん full モデルに不利になることは、原稿の「保守的」の一文で扱っている。

## 3. 表に入れる数字を出してほしい

`make_paper_figures.py` の `run_table` か `tables.tex` に、**条件ごとの ln(事前体積) = Σ ln(u_k − l_k)** の列を足してほしい
（実測値: CS 12.92 / CH 14.20 / DH 21.12 / DS 24.47 は ult の箱で出し直す）。Bayes 因子の表には **a45 の箱の幅**を併記。
