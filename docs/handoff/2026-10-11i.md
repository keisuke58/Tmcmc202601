# クラウド側 → GPU 側（2026-10-11i）: 今ある一番いい run で図を作る（CS・CH は確定、DS・DH は p2 の仮）

ユーザー依頼: 確定した CS・CH と、DS・DH の現状の一番いい run（p2 段）で、**昔（BMB 版・修論）と同じ体裁の図**を作る。
DS・DH は ult が出たら同じコマンドで差し替える前提の**仮**。

## コマンド

```
cd ~/Tmcmc202601 && git pull
PY=~/miniforge3/envs/klempt_fem2/bin/python3
OUT=docs/revision/EML_submission/figures/provisional_2026-10-11
$PY tools/make_paper_figures.py data_5species/main/_runs/paper_gateoff \
    --out-dir $OUT \
    --p2-glob-CS 'CS_ult_wide2_sd4_seed*'                 --p1-glob-CS 'CS_p1_mut120*' \
    --p2-glob-CH 'CH_ult_mut150_wide2_noph_sd4_seed*'     --p1-glob-CH 'CH_p1_mut150*' \
    --p2-glob-DS 'DS_p2_wide80_p18k_wide2_seed*'          --p1-glob-DS 'DS_p1_wide80_p3k*' \
    --p2-glob-DH 'DH_p2_nonarrow_w3_noph_p14k_seed*'      --p1-glob-DH 'DH_p1_mut80*' \
    --skip knockout ident
```

- **出力先は `EML_submission/figures/provisional_2026-10-11/`。BMB_submission/figures は上書きしない**（`--out-dir` を必ず付ける）。
  数値（paper_numbers.json・tables.tex）は `--out-dir/../generated/` に出るので、それも provisional として一緒に commit（`docs/revision/generated/` の本番は触らない）。
- DS・DH の glob は**完走していて 3 seed そろっている一番新しい p2 群**に合わせること。上の名前が走行中・未完なら、その前の完走した群（DS は `p12k`、DH はその前の p2）に差し替え、どれを使ったかを報告に書く。
- 図 2（`paper_fig2_phi_transposed.pdf`）がいちばん大事（組成の時間変化、モデルと実測）。ほか 4 枚（heatmap・violin・phase・UMAP）も出たものを全部。
- PDF と、各条件の RMSE（paper_numbers.json の値）を一覧にして `docs/handoff/gpu_2026-10-11_figs_provisional.md` に書き、commit・push。
