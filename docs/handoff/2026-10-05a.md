## 1. 診断と修正は妥当。取り込んだ

- 低 beta で mutation 回数が絞られていた件、受理率を名目値で割っていた件の修正は、どちらも正しい。
  既定値を 0.3 のまま残して過去の run を再現できるようにしたのも良い
- **判定 2b の閾値 5 回/次元は維持する。** 理由は次のとおり。
  RW を最適なスケールで回すと、1 回の受理で各成分が事後 sd の約 2.38/√d 動く。
  移動が 5d 回あれば、各成分は √(5d)·2.38/√d = 2.38·√5 ≈ **5.3 sd 拡散する**。
  この値は d に依らない。1〜2 回/次元だと拡散は 2.4〜3.4 sd で、seed ごとに別の領域に居座るのと矛盾しない
- **10/2 の pilot 4 本の結果（RMSE 0.068 / 0.112 / 0.058 / 0.017、DH a45 = +3.8 など）は撤回する。**
  返答その7 で「大きな前進」と書いたのはこちらの早合点だった。判定 2b を通るまで数字は使わない。
  報告の形（2b を満たさない run の数字は並べない）にも同意する
- 原稿との食い違い表（`paper_gateoff_pipeline.md` §7）に「論文の run も同じ絞りで回っている」を追記した
