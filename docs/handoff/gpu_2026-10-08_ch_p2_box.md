## 1. CH p2（`mut150`）: 判定は全 PASS だが a12・a14・a15 が下限に積んでいた

**`check_paper_runs.py` の「箱の端」は両端の合計を出すので、片側 20% の基準をそのままは読めない。**
片側に分解すると全 3 seed で**すべて下限側**だった（上限側は 0.00）:

| 成分 | 箱 | 下側 5% の割合（seed123 / 42 / 7） | CH p1 (`mut150`) | 判断 |
|---|---|---|---|---|
| a12 | [−1.0, +2.5] | **0.23 / 0.24 / 0.23** | ≤0.10 | 片側 0.20 超 ＋ 前段から +0.13 → 広げる |
| a15 | [−1.0, +1.0] | **0.24 / 0.23 / 0.24** | 0.10 | 片側 0.20 超 ＋ +0.14 → 広げる |
| a14 | [−1.0, +1.0] | **0.20 / 0.21 / 0.22** | 0.10〜0.11 | 片側 0.20 ちょうど以上 ＋ +0.10 → 広げる |
| a13 | [−1.0, +3.0] | 0.19 / 0.17 / 0.19 | 0.10 | 0.20 未満 → **触らない**（08m の CS で a13 を触らなかったのと同じ） |

**08d の停止基準（片側 20% 以上、または前段から 0.1 以上の増加）を 3 成分が両方とも満たす。**
08m §2 が CS に「同じ規則で広げる」と書いた理由（条件ごとに基準の当てはめ方が違うと査読で突かれる）がそのまま当てはまるので、
**CH も ult に進めず p2 を回し直した。** 混合不足ではない（移動 10.2〜10.5 回/次元、受理率 0.15）。

### 投入した設定（3282-3284、2026-10-08）

```
STAGE=p2 TAG=CH SEED=$S N_MUT=150 RUNTAG=mut150_wide
OVERRIDE='1:-5:2.5;11:-5:1;16:-5:1'
PREV=_runs/paper_gateoff/CH_p1_mut150_seed$S
```

- **下限だけ −5 に広げ、上限は論文の箱のまま**（08m §2 の「下限側に積んでいるなら下限だけ −5 に広げる。上側に積んでいるなら触らない」をそのまま適用）。
- 粒子数は 2000 据え置き・N_MUT 150 据え置き。**変えたのは箱だけ**にして、判定 4 が箱のせいかを切り分けられるようにした。
  （DH と違い CH は判定 4 が PASS なので、粒子を増やす理由が無い。必要なら ult で 5000 になる。）
- **旧 `CH_p2_mut150` は 3 seed とも完走済みで残してある**（張り付きの記録として査読の回答に使える。qdel していない）。
