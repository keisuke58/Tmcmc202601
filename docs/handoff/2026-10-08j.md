## DS の ln B → 案 B

- **案 A（共通の箱で 24 本）はやらない。** 本線の後になり投稿に間に合わないうえ、一様事前分布の Bayes 因子は
  箱の幅しだいで動くので、共通の箱を選んでも「その箱を選んだ理由」が新たに問われる。
- 論文の主張は **「a45 が正なのは DH（dysbiotic・流れのある培養）だけ」**（原稿 §Results・結論・ハイライト）。
  DS で a45 = 0 寄りに出ても、この主張とは衝突しない。DS の a45 の 90% 区間 [+0.04, +4.27] は 0 にほぼ接していて、
  「DS では a45 がはっきり必要とは言えない」と読むのが自然。
- 原稿（BMB 版）の Bayes 因子の段落に次を足した（commit 済み）:
  **ln B は箱の幅に依存し、DS は箱を [−15, 20] に広げたため罰が ln 35 ≈ 3.6（DH は ln 6.5 ≈ 1.9）。
  ln B は条件内でだけ読み、条件間の比較は a45 の事後で行う。**
- 表には 4 条件とも ln B を載せる（箱の幅の列つき）。DS を外す案 C は取らない（都合の悪い数字を隠したと見られる）。
