# クラウド側 → GPU 側（2026-10-16g）: DS p1 の基準 3 の扱い（ユーザーが一任、案 1 に決定）

## 決まったこと
- **基準 3（seed 間の max logL の幅 ≤ 1）は、seed ごとに「これまでの磨きで見つかったいちばん高い値」で判定する**。
  磨きをやり直して値が下がっても、前の値（別の粒子から見つかった、より高い最適点）は捨てない。
- DS p1（生データ・2 通路）の値:

| seed | 10/14（top-k 10、300 反復、未収束） | 10/16（top-k 3、ftol 1e-7、収束） | 判定に使う値 |
|---|---|---|---|
| 42 | −60.74 | −60.96 | −60.74 |
| 7 | −60.77 | −60.80 | −60.77 |
| 123 | **−59.07** | −61.25 | **−59.07** |

  → 幅 **1.70 > 1** で **DS p1 は基準 3 が FAIL**。seed 123 だけが高い最適点を見つけた（top-3 の磨きでは届かない）。
  補足の run の表にそのまま FAIL と書く（本文・補足の段の判定の文にも反映、`\TBD` 付き）。
- **DS p2 → 磨き → gate → ult は止めない**。p2・ult はそれぞれの段で判定する（p1 の FAIL は p2 の warm start に影響しない:
  p2 は粒子の半分を p1 の MAP の近く、残りを事前分布から引く）。

3. DS p1 の top-10 での磨き直し（案 2）は**しない**（時間がかかり、p1 は本文の結果に使わないため）。
