## 1. 本線（最優先・vancouver から埋める）

| 条件 | いまの段 | 次にやること |
|---|---|---|
| **DS** | p1 `wide80_p3k`（3000 粒子・N_MUT 100・3 seed とも PREV=pilot seed123）走行中 | 判定 0〜4 ＋ **a33 < −5 の割合**を報告。重みが seed 間 ±0.10 でそろえば判定 4 の FAIL は二峰のせいとして p2 へ（08h） |
| **DH** | p2 nonarrow → ult `nonarrow_sd4` が依存で待機 | p2 が PASS なら ult はそのまま走らせてよい |
| **CS / CH** | p2 走行中 | PASS したら ult（RUNTAG 末尾 `sd4`） |

- **ult の設定**: 5000 粒子・N_MUT 80・walltime 22h・箱は **平均 ± 4σ**（`ULT_NSIGMA` 既定 4）・OVERRIDE は p2 と同じ（08a・08f）。
- **判定の規則**: 0〜4・2b を通った段は返事を待たずに次へ。**3・4 の FAIL、片側の端 5% に 0.20 以上、または前段から 0.1 以上増えた成分**があれば止めて報告（08d）。端の 0.10〜0.15 は一様と同じで問題ない。
- スクリプトを変えたら**先置きのジョブは投げ直す**（PBS は qsub 時点の内容で走る）。
