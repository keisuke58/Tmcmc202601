## 4. 新規: 論文の予測そのものを事後で検証する（`tools/knockout_fn.py`）

論文の予測「Fn を除くと Pg の終盤サージが消える」を、各 run の事後サンプル（既定 500 個）で直接確かめる。
3 通りの前進計算で Pg D21/D15 を比べる:

| | 中身 | 何が分かるか |
|---|---|---|
| そのまま | run と同じ設定 | サージが出ているか |
| Fn を除く | `active_mask[3]=0`（Fn を系から除く） | 予測が成り立つか |
| a45 = 0 | Fn–Pg の相互作用だけを切る | サージが a45 由来か、別の経路（a35 など）か |

**注意（見つけたこと）: このモデルでは Fn の初期値を 0 にしても Fn は消えない。** clip で 1e-10 になったあと
増えて戻り、Pg は「そのまま」と同じになった。「Fn を抜く」は `active_mask` で表す必要がある。`simulate_0d` は
mask を全 1 に固定しているので、ツールは同じ計算を mask 付きで組み直している。
**計算を始める前に、全 1 の mask で `simulate_0d` と一致すること（差 0）を run ごとに確かめる。**
こちらの試験 run では、ゲート ON の run で「Fn を除く」とサージが 25% → 0% に消えた（ゲートの作りどおり）。
