`gpu_2026-10-08_p2_verdicts.md` を読んだ。片側に分けて読み直したのは正しい。3 つとも返事と同時に投げてよい（枠は 9 本で収まる）。

## 2. CS: 案 A（a13 の上限だけ 20 に広げて p2 をもう一度）

規則（片側 0.20 超なら広げる）を条件ごとに変えない。a33 を外したら a13 が伸びた、という読みも妥当。

STAGE=p2 TAG=CS SEED=$S N_MUT=160 RUNTAG=mut160_wide2

## 3. DH: 3 回目の p2 は a45 の上限と 5000 粒子を同時に変えて 1 回で済ませる

- **FAIL の段から先へは進めない**（08k の規則は例外にしない）。a45 は論文の主張そのものの成分で、そこに FAIL と上限での切断が重なったまま ult に進むと、査読で一番突かれる所が一番弱くなる。
- 切り分けは諦めてよい（a45 の上限と粒子数を同時に変える）。

```
STAGE=p2 TAG=DH SEED=$S N_PART=5000 N_MUT=80 RUNTAG=nonarrow_a45
OVERRIDE='12:-15:20;5:-15:20;6:-15:20;18:-15:20;13:-15:20;0:-5:5;11:-3:3;19:-0.5:20'
PREV=_runs/paper_gateoff/DH_p1_mut80_seed$S
```

- a45 は**上限だけ** 20（下限 −0.5 は端に積んでいないので触らない）。
- **ln B への影響はない**: ln B は pilot 段（論文の箱 [−0.5, 6]）で計算しているので、p2 以降の箱を変えても 08i / 08j の方針と原稿の「ln 6.5 ≈ 1.9」はそのまま。補遺の箱の表には段ごとの箱を書く。
- 見込み: p2 は 3000 粒子で約 7h → 5000 粒子で約 12h、ult 22h。今夜投げれば 10-10 朝に ult が終わり、10-12 に間に合う。
- 通ったら ult は `RUNTAG=nonarrow_a45_sd4`、PREV=`DH_p2_nonarrow_a45_seed$S`、OVERRIDE は同じ。図の glob は `--p2-glob-DH 'DH_ult_nonarrow_a45_sd4_seed*'`。
- **報告では a45 の 5 / 50 / 95% と上側の端の割合を必ず出す。** 上限を 20 にしてもまだ上に伸びるなら、
  原稿は「a45 > 0（下側は決まる）、大きさの上側はデータで決まらない」と書く。それも一つの答えなので、もう一度広げ直す必要はない。
