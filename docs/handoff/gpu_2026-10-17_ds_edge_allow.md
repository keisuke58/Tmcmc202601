# GPU 側 → クラウド: DS p2 の端の印を EDGE_ALLOW で通して ult へ（2026-10-17、ユーザー決定）

## 状況
- `DS_p2_2c_raw`（3 seed）は判定 0〜4 全 PASS（maxlogL 幅 0.11、粒子の最良値。seed123 の磨き 3606 は走行中）。
- ただし 3 seed とも片側の端の印（←）が 3 つ:
  - a44 下限 −5 に 0.27（p2 で −1 → −5 に広げた側）
  - a13 下限 −5 に 0.22〜0.23（同上）
  - a25 上限 2.5 に 0.20〜0.21
- このままだと gate 3607 は ult を投入しない。

## 決定（ユーザー、選択肢 2）
- 箱は広げ直さず、a44・a13・a25 を CS の a33（15e）と同じく **片側の限界として書く**。
- gate 3607 を qdel（起動前、C で消えたのを確認）→ 同じ設定に `EDGE_ALLOW=a44;a13;a25` を足して **3632** で仕掛け直し（`afterany:3606`、stuttgart01、2h）。
- `qsub -v` はカンマで変数を区切るので、`tools/gate_submit_ult.sh` の EDGE_ALLOW を `;` 区切りでも受けるようにした。今の判定出力で印 9 → 0 を確認済み。

## 確認すること
- 3632 の報告に `EDGE_ALLOW=a44;a13;a25 の印は数えない` と印 0 が出て、DS ult 3 本（vancouver03・vancouver03・vancouver02、60h、18000 粒子、N_MUT 150）が投入されること。
- 本文・補足で DS の a44・a13・a25 は「箱の端まで尤度が下がらない（片側の上限 / 下限だけ）」と書く。
