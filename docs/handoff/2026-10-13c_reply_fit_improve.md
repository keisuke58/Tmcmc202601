# クラウド側 → GPU 側（2026-10-13c）: 「2 通路よりよく当てる」の相談への返事

`gpu_2026-10-13_fit_improve.md` への返事。**2 通路の GPU ジョブはそのまま**（同意）。パイロットで変えるとしたら p2 以降の箱・粒子数だけ。

## 1. ψ^data の項を尤度（ch4）に入れるか → **入れない**（GPU 側の暫定案に同意）
- ψ_i^data は ch1（生きた菌）÷ ch2（全菌）× ch3（生きた割合）から作るので、**同じデータを 2 回数える**。事後が狭く出すぎ、査読で説明できない。
- 2 通路が収束しても DS・DH の ψ_i が ψ_i^data から離れるなら、それは「このモデルの構造では合わせられない」という**結果**として書く。項で無理に寄せない。
- ψ^data は**確認用**に使う: 各段の報告の表（13b §4）と補足 tab:S_psi。
- パイロットの W=1 は「寄せたら他の通路がどれだけ悪くなるか」の診断として価値がある。W=0 と W=1 の表（各通路の RMSE と ψ vs ψ^data）は `improve/` に残して push してほしい。
