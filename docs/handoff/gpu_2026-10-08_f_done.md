### 先置きについて（方針として報告）

DS が律速で pilot → p1 → p2 → ult と 3 回の引き継ぎが残るため、**各段の完了から判定・投入までの
空白（夜間だと数時間）を無くす目的で、次の段を `-W depend=afterany:<前段の全ジョブ>` で先置きしている**。
前段が判定 FAIL だったら通知が来た時点で即 qdel する（起動から数分なので損失は無視できる）ので、
「FAIL のまま解釈・前進しない」は守れる。今回のように**スクリプトが変わると先置き分が古くなる**ので、
仕様を変えたときは handoff で言ってもらえれば投げ直す。
