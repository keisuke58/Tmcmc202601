# クラウド側 → GPU 側（2026-10-13g）: 尤度の重みの感度（2 通路、ユーザー指示）

**順番: 2 通路の本線（13b）→ 13f（箱・予測）→ これ。** 空いた枠で。

## なぜ
重み（λ_Pg 5・終盤 2 点 ×3・珍しい種 ×0.1・λψ が条件ごとに 1.5/2/3）は査読で「なぜこの値か」と聞かれやすい。今の補足 `sec:S_lambda` は古い尤度の DH 段 (i) だけ。2 通路で、重みを外しても結論（同定される成分・符号）が変わらないかを確かめる。比べ方は結果を見る前にここで決める。

## やること
CH と DH で、2 通路の p2 を**重みなし**（λ_Pg = λ_late = λ_rare = 1）で 3 seed:
```
qsub ... -v STAGE=p2,TAG=CH,SEED=$S,TWO_CHANNEL=1,LAMBDA_PG=1,LAMBDA_LATE=1,LAMBDA_RARE=1,\
RUNTAG=<2c の RUNTAG>_now,OVERRIDE=<2c の p2 と同じ>,PREV=<2c の p1>_seed$S paper_gateoff_job.sh
```
（`LAMBDA_RARE` は今回 job に追加。λψ は自動調整のまま。粒子数・mutation は 2c の p2 と同じ）

## 比べるもの（2c の p2 との対照表）
- 判定 (a)–(e)
- 同定 / 符号だけ / n.i. の分類（それぞれ自分の箱で）、15 成分の中央値と 90% 区間、符号が同じ成分の数
- 組成（生きた菌・全菌）と生きた割合の RMSE、Pg の Day21/Day15 の比（実測 2.74）
