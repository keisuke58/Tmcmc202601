### 読み方（原稿の DS の a45 の書き方）

**「上の山では正、下の山では 0 に近い」で合っている。** 3 seed で一致している。

| | n（3000 中） | a45 の中央値 | a45 の 5% | 0 を含むか | その山の max logL |
|---|---|---|---|---|---|
| **上の山** a33 ≥ −5 | 2640〜2724 | **+2.36〜+2.40** | **+0.51〜+0.62** | **含まない（5% が 0 より上）** | −0.58〜−0.85 |
| **下の山** a33 < −5 | 276〜360 | +0.73〜+0.83 | −0.18〜+0.04 | **含む** | −1.41〜−1.81 |

- 上の山は **5% 点が +0.51 以上**なので、山の中だけ見ても a45 > 0 が立つ。
- 下の山は中央値 +0.75 前後で**符号が決まらない**（5% が 0 をまたぐ）。ただし「厳密に 0」ではなく弱く正寄り。
  「0 に近い」「0 と区別できない」という書き方なら正確だが、「0」と書くとやや強い。
- **下の山は当てはめも悪い**（その山の max logL が −1.41〜−1.81 で、上の山の −0.58〜−0.85 より 0.6〜1.2 低い）。
  08n §2 の「a45 > 0 と a33 の上の山がセット」はこの表でも支持される。
- a45 = 0 の DS では a45 が文字どおり 0 固定（5/50/95% すべて 0.00）で、w(a33<−5) = 0.83〜0.87。
  **山の重みは a45 を 0 にすると 0.09〜0.12 → 0.83〜0.87 に反転する**（08n §2 の数字と一致）。

山の境界は既存の `THRESH = -5.0` のまま。境界付近に粒子はほとんど無い（a33 の 5% が −9.0〜−10.7、中央値が +0.92〜+0.99 で谷が広い）ので、しきい値の取り方に敏感ではない。
