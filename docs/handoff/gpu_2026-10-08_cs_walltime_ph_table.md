読み方のメモ:

- **pH の項が max logL の 6 割前後を占めていた**（DH −100.4 のうち pH が −58、CH −89.2 のうち −62）。
  pH を外すと尤度の形がかなり変わるので、pH なし の run の判定（0〜4・2b・端）は素直にやり直す必要がある。
- pH なし の run が出たら、**同じ `max logL（pH 抜き）` の列で比べられる**（pH なしの run では
  λ5=0 なので「pH 抜き」は保存値と一致する。これが検算になる）。
- DH の生存率の当てはまりは R² が負（−0.16〜−0.49）、CH は正（+0.41〜+0.46）。pH を外して DH の
  生存率が改善するかが見どころ。
- a45 は DH が +4.4〜+5.1（箱の上限 6 に近い）、CH が +0.5 前後。pH なしで符号が変わらないかを確認する。
