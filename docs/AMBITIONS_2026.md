## 1. パフォーマンス目標（数値で叩き切る）

| 指標 | 現状 | 目標 | 倍率 |
|------|------|------|------|
| **TMCMC 1000粒子** | 90h | **1h** | **90×** |
| **DeepONet MAP 外挿誤差** | 大 | **RMSE < 5%** | 実質解消 |
| **E2E パイプライン** | 手動 | **1コマンド 10分** | 完全自動 |
| **テストカバレッジ** | 不明 | **>80%** | 計測可能 |
| **CI 通過時間** | - | **<5分** | 即時フィードバック |

### 1.1 TMCMC 90h → 1h の道筋

- [ ] **GPU 並列化**: JAX `vmap` + `pmap` で粒子バッチ評価
- [ ] **サロゲート統合**: DeepONet で尤度推定、ODE はフォールバックのみ
- [ ] **適応サンプリング**: ESS 閾値に応じた動的粒子数
- [ ] **チェックポイント**: 中断再開可能、分散実行対応

### 1.2 DeepONet 精度の壁

- [ ] **学習データ拡張**: 事後分布から 10× サンプル生成
- [ ] **不確実性定量**:  epistemic + aleatoric の分離
- [ ] **範囲外検出**: 自動 ODE フォールバック閾値
