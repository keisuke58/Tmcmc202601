## 初期値（phi_init.json、2026-10-12）

`phi_init.json` に、各条件の MAP と同じ run が推定で実際に使った初期値（`run_record.json` の `phi_init`、Day 1 の組成を正規化して [0.001, 0.99] に切ったもの）を置く。
FEM（pde-fem-biofilm `run_calibrated.ps1`）は θ（`<C>.json`）と同じ commit の `phi_init.json` の `phi_init_state`（前進計算の実際の出発点、和 0.999999 にそろえた値）を `write_eco_cfg.py --phi-init` に渡す。
旧推定の `config.json` の値とは最大 0.013 ほど違うので、較正と同じ軌道にはこちらを使う。DS・DH は確定したら足す。

### 初期状態の小さな食い違い（2026-10-15 に気づいた。結果への影響はごく小さい）
`phi_init` は Day 1 の組成を正規化してから [0.001, 0.99] に切るので、和が 1 をわずかに超える（CH 1.001、CS 1.0001）。
`make_initial_state` は和が 0.999999 より小さいときだけ 0.999999 に引き上げ、超えるときは縮めないので、空隙率 φ0 = 1 − Σφ が
わずかに負（CH −0.001）で始まり、1 段目の clip（φ0 ≥ eps）と拘束 Σφ + φ0 = 1 で直る。較正はすべてこの状態で回っているので、
FEM でも同じ `phi_init_state`（＝ `phi_init` そのまま）を渡せば較正と同じ軌道になる。直すなら全条件の回し直しになるので、今回は直さない。
