## 来そうな指摘と答え

| 来そうな指摘 | 今ある答え（どこに） | 足りなければ追加でやること |
|---|---|---|
| 組成は合計 1 なのに独立として尤度を立てている（区間が狭すぎる） | 本文の限界（Sect. limits）、回収テスト（S7、CH は同定 6 のうち真値を含むのは 2） | 組成用の尤度（対数比の変換など）で推定し直し、分類が変わらないことを示す（GPU で数日） |
| 力学の雑誌なのに力学が薄い | 成長応力の確認（補足） | 修論側の FEM で事後分布から応力の幅を出した結果（pde-fem-biofilm、`data/posterior_final/` と UQ の計算）を図 1 枚に |
| 同定性のしきい値 0.8 が恣意的 | しきい値を変えた表（補足）、Fisher 情報（S6） | なし |
| 尤度の重みが恣意的 | 重みの感度（S9） | 重みなしの推定を GPU で |
| CS が合わない、DH の段 (iv) が通らない | 本文の限界に明記 | モデルの限界として認める（直すのは次の論文） |
| 生物学の主張が強い | 「モデルからの仮説」として控えめに | 言い回しをさらに弱める |
| 他の手法（HMC、プロファイル尤度）との比較がない | Fisher 情報で別の角度から確認 | プロファイル尤度を 1〜2 成分だけ |
| 実験データがない（再現できない） | Zenodo に事後の粒子・設定・コード、データは著者に請求で入手可（Heine と合意） | なし |

## 進め方
1. 読んで 1〜2 日寝かせる。
2. 指摘を 3 つに分ける: 文章で直す／追加の計算が要る／同意できない（理由を書いて丁寧に反論）。
3. 全部に一つずつ答える（指摘 → 対応 → 原稿の場所。共著者への回答 `response_to_coauthors.tex` と同じ形）。
4. 締切が厳しければ延長を頼む。重い指摘は Junker 先生・Meisam を早めに巻き込む。
