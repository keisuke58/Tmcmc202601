# P3 設計: 点モデルの成長で α̇ を駆動する（クラウド側の設計、2026-10-10）

目的: 種重み（仮定）をやめて、**較正済みの点モデル自身の成長**を場の成長変数 α に入れる。条件の違いが恣意的な重みでなく θ（4 条件の最終 MAP）から応力に出るようにする。
実装は IKMHIWI03 の Fortran 要素。ここでは式・時間軸・段階・検証だけ決める。

参照: Klempt et al. 2024（`FEM/A Hamilton principle-based model for diffusion-driven biofilm growth.pdf`）式 (32)(36) と Table 1 の局所残差、`data_5species/main/estimate_paper_jax.py`（尤度・dt・c_const）。

---

## 0. 先に知っておくべき制約（設計を左右する）

**尤度は全量 Σφ の絶対値を縛っていない。**
`estimate_paper_jax.py` の 3 チャネルはどれも割合だけを見る:

| チャネル | 比べるもの | 正規化 |
|---|---|---|
| ch1 種 | φ̄_i = φ_i ψ_i | データ `normalize=True`、予測も Σ で割る（l.998） |
| ch2 全種 | φ_i | Σφ で割る（l.1018） |
| ch3 生存率 | Σφ_iψ_i / Σφ_i | 比 |

したがって Σφ(t) の**形**は θ から決まるが、**データが決めた量ではない**（モデルの予測）。
これを α̇ の駆動に使うなら、事後のばらつきが小さいことを先に確かめる必要がある（§4 段階 0）。
ばらつきが大きければ、条件間の応力差は「同定されていない量の差」になり、査読で突かれる。

## 1. 時間軸: s の置き方

- 点モデル: dt = 1e-4（`--dt` 既定）、**t_pm = 0.2375 が Day 21**。
- Klempt: T* = t / t_ref、T* ∈ [0, 1] になるように t_ref を選ぶ。
- **決め方: t_ref = 21 日（実験の全期間）。すると T* = day/21、t_pm = s·T*、s = 0.2375。**
  - s は **4 条件で共通の 1 つの定数**（条件ごとに変えると時間軸がずれて比較が壊れる）。
  - 前提: 4 条件とも観測日 3・6・10・15・21 の t_pm への対応が同じ。**IKMHIWI03 側で 4 つの json の元 run の `config.json`（t_days と idx）が同じか 1 回確認すること。**
  - Klempt の速度定数（k_α, g, r, d：単位 T*⁻¹）はこの T* でそのまま意味を持つ。
- **T* > 1 は較正の外（Day 21 より後）。** 今の T*=5 は 105 日相当で、点モデルを t_pm = 1.19 まで外挿している。
  - P3 の 4 条件比較は **T* ≤ 1**（観測日 T* = 3/21, 6/21, 10/21, 15/21, 1 で図を切る）。
  - T* > 1 を出すときは「外挿」と明記するか、Φ を T* = 1 で凍結した版を並べる。
- FEM の時間刻み: Δt_pm = s·ΔT* が較正時の dt = 1e-4 以下になるように点モデルを部分刻みする（ΔT* = 1e-3 なら 3 部分刻み）。較正と同じ軌道を再現するため。

## 2. 式

### 2.1 α の発展（Klempt の局所残差と同じ形）

Klempt Table 1 の局所残差は
  (α_{n+1} − α_n) / ((1+α_{n+1}) Δt) − k_α (φ_{n+1} − φ_n) / Δt = 0
つまり ln(1+α) が phase field φ の増分に比例する。これと同じ形で、駆動を点モデルの全量に替える:

  **ln(1+α_{n+1}) − ln(1+α_n) = κ · χ(x) · (Φ_{n+1} − Φ_n)**,  Φ = Σ_{i=1..5} φ_i（点モデル）

- J_g = 1 + α、F_g = (1+α)^{1/3} I（今の要素と同じ等方成長）。
- χ(x)：成長が起きる場所の指示関数。Klempt の phase field φ_field をそのまま使う（バイオフィルム外で 0）。
- **κ は 4 条件で共通の 1 スカラー。** 条件ごとに合わせない（合わせると種重みと同じ恣意性が戻る）。決め方は CH の Day 21 で J_g が今の基準計算と同じになる値、のように 1 条件・1 時点で 1 回だけ。
- Φ に Σφ_i（死菌・基質も体積を占める）を使うのを本線、Σφ_iψ_i（生菌だけ）を感度として 1 本。
- 結果: 条件の差は Φ(t) の形の差だけから出る。重みは消える。

### 2.2 点モデルをどこで解くか（2 段階）

**段階 1（一方向・表引き）**: 点モデルは条件ごとに 1 回だけ（栄養は一様、c = c_const = 25）解いて Φ(t_pm) の表を作る。要素は T* → t_pm = s·T* で表を引いて 2.1 を積分する。
- 要素の変更は α の更新式だけ。内部変数は増えない。
- 場の栄養 c(x) は α に効かない（効くのは χ を通してだけ）。

**段階 2（積分点に点モデルを埋め込む、本筋）**: 各積分点に点モデルの状態 q = (φ_1..5, φ_0, ψ_1..5, γ)（12 個）を内部変数として持たせ、c_const を局所の栄養に置き換える:
  c_pm(x, t) = c_const · c(x, t)  （c は Klempt の正規化栄養、源で c = 1）
- 源の近くでは較正と同じ軌道、栄養の届かない所では成長が落ちる → 条件差が場の形にも出る。
- 局所の解き方は較正時のソルバと同じ陰的 Newton（部分刻み、§1）。
- 消費項 g φ_field（Klempt 式 35）は段階 2 でも当面そのまま。点モデルの生菌量で消費を変えるのは段階 3（任意）。
- **c < 1 は較正の外**（較正は c_const 一定だけ）。結果の章ではそう書く。
- 費用: 24³ × 8 積分点 ≈ 1.1×10⁵ 点 × 12 変数、局所 Newton は点ごと独立なので Fortran で問題ない。

## 4. 段階と担当

| 段階 | 中身 | 担当 | 前提 |
|---|---|---|---|
| **0** | 事後の Φ(t) のばらつき: 各条件の ult 事後から 200 標本、Φ(t_pm) と Φ(0.2375)/Φ(0) の 90% 帯。条件間の差が帯より大きいか | GPU 側（`_runs` の ult 事後がある所、CPU で数分） | ult がそろった条件から |
| 1 | 表引きで α̇ を駆動、κ を CH で 1 回決める、V1・V2 | IKMHIWI03 | CH.json は済み、他 3 条件は json 待ち |
| 2 | 積分点に点モデル、c_pm = c_const·c、V3・V4 | IKMHIWI03 | 段階 1 が通ってから |
| 3 | 消費・応力の帰還（Klempt 式 30 の φμ(I:Ce−3)） | 未定 | P3 の範囲外でもよい |

**段階 0 の判定**: 4 条件の Φ(Day21)/Φ(0) の 90% 帯が条件間で重ならない → 段階 1 に進む。重なる → Φ は「条件差を運べない量」なので、駆動を組成に依存する量（例: 生存率 ch3、これはデータで縛られている）に替える案を再設計する。
