## 4. GPU の結果で見てほしいところ

- **DH の a35（θ[18]）**: CPU では箱をどこまで広げても下端に張り付く（−4 → −15）。
  GPU の事前分布なし run で**周辺事後が −15 付近に積み上がるか**が本題。積み上がれば、
  論文 §6.8 の「`r_i < 0.43` なので過剰パラメータではない」は箱が切っているだけ、と言える。
- **σ=6 の run**: CPU では端の張り付きを止めると当てはまりが約 18% 悪化した（DH・CS で一致）。
  GPU でも同じ代償が出るか。
- **a45（θ[19]）**: DH で正（+3.7〜+4.3）を保つか。論文の主張（Fn が Pg のサージを運ぶ）の中心。
- **数値の一致は期待しない**（上の ⚠️ の 3 点）。数値まで揃えたいなら `--use-exp-init --lambda-pg 1
  --lambda-late 1` を付ける。種ごとの σ は CLI にまだ無い。
